# Listing a staffing/contracting employer vs. the client site

Generic guidance on how to represent a job where a staffing/contracting
company is the actual employer of record but the candidate works
full-time, embedded, at a different company's site. Prompted by the
candidate's Aviya Aerospace Systems -> Pratt & Whitney Canada
relationship: Aviya is the employer of record, Pratt & Whitney is where
the candidate is actually embedded full-time and does all their work.

## Core rule: list whoever paid you, not just where you sat

Background checks and reference verification go through payroll
records. If a resume names the client site as the "employer" but the
staffing/contracting company was who actually issued paychecks, that
mismatch is a real verification failure, not just a style question.
The employer-of-record name belongs in the company slot; the client
site is added context, not a replacement.

## Two accepted patterns

1. **Agency-first (the default recommendation for a single extended
   placement at one client):**
   ```
   <Staffing/Contracting Company> — <Role>
   Contracted to <Client Company>, <dates>
   ```
   Reads to a skimming recruiter almost like a normal FTE role while
   staying verification-accurate. This is the standard pattern when one
   agency placed the candidate at one client for a meaningful stretch,
   rather than many short client engagements (which would instead group
   multiple client sub-roles under one agency header — a different
   pattern for a different situation, not applicable to a single
   long-term placement).
2. **Client-first with a contractor tag** (when the client name carries
   more recognition value and the candidate wants it to read first):
   ```
   <Client Company> (Contract via <Staffing/Contracting Company>) — <Role>, <dates>
   ```

Both are legitimate and commonly used; the choice is about which name's
recognition value should lead, not about which one is "more honest" --
both name the true employer, just in different position/emphasis.

## What NOT to do

Listing only the client company name with no mention of the actual
employer of record is the pattern that causes background-check
mismatches and reads as inaccurate once anyone checks. Per this
pipeline's hard rule 1 (never fabricate), the true employer relationship
needs to be represented somewhere in the entry, not silently dropped
for a cleaner-looking company name.
